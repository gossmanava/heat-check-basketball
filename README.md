# Heat Check

A polished, dependency-free browser basketball game. Open `index.html` in a modern browser.

## Controls

- Drag backward from the basketball to aim and set power.
- Release to shoot.
- Make two baskets in a row to catch fire. Regular baskets are worth 2 points; fire-streak baskets are worth 3.
- Personal records for 30- and 60-second modes are saved in the browser.
